# Mini Calendar (Kotlin, Android 16 / API 36, minSdk 26)

No ads, no login, no INTERNET permission. Events are stored locally.

## Build the APK
**Android Studio:** File > Open this folder, wait for Gradle sync, then Build > Build APK(s).
Output: app/build/outputs/apk/debug/app-debug.apk

**GitHub (no PC needed):** push this folder to a new GitHub repo. The "Build APK" workflow runs
automatically (or Actions > Build APK > Run workflow). Download "MiniCalendar-APK" from the run's Artifacts.
